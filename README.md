# 우리사이 (Dear Us) - 부부 일정 & 기념일 공유 프로그램 💍

부부 사이에 일정, 기념일, D-Day, 러브노트, 장보기/할일을 함께 공유할 수 있는 감성적이고 세련된 웹 프로그램입니다.

---

## 🌟 주요 기능

1. **감성 캘린더 (달력)**
   - 💜 우리 둘이 함께하는 일정
   - 💙 남편 개인 일정
   - 💖 아내 개인 일정
   - 🏡 양가 가족 행사
   - 🎂 기념일 하이라이트
   - 날짜별 상세 일정 관리, 시간, 장소, 메모 등록

2. **기념일 & D-Day 카운트다운**
   - 결혼한 지 D+OO일 자동 연산
   - 처음 만난 지 D+OO일
   - 다음 기념일까지 D-Day 카운터
   - 100일, 1000일, 주년 단위 마일스톤 자동 계산
   - 축하 폭죽(Confetti) 터뜨리기 효과 🎉

3. **서로에게 남기는 러브 노트**
   - 퇴근길 응원, 감사, 사랑의 한마디를 핀보드 메모지로 공유
   - 귀여운 감성 스티커 부착

4. **부부 할일 & 장보기 & 버킷리스트**
   - 마트 장보기 목록 실시간 체크
   - 집안일 분담 (남편/아내/함께)
   - 함께 이루고 싶은 버킷리스트

5. **소중한 순간 (추억 다이어리)**
   - 사진과 감성적인 글귀로 남기는 부부 타임라인
   - 하트(좋아요) 남기기

6. **스마트폰 실시간 공유 기능**
   - 같은 Wi-Fi 환경에서 스마트폰 카메라로 QR 코드를 비추면 즉시 접속 가능!
   - 4초 주기 실시간 자동 동기화로 남편이 폰에서 등록한 일정이 아내의 화면에 즉시 반영

---

## 🚀 실행 방법

### 방법 1 (가장 간편)
- **바탕화면**의 `우리사이_부부일정관리.bat`를 더블클릭합니다.
- 또는 프로젝트 폴더 내 `실행하기.bat`를 더블클릭합니다.
- 자동으로 브라우저가 열리며 바로 실행됩니다.

### 방법 2 (터미널)
```bash
npm run dev
```
접속 주소: `http://localhost:5173`
스마트폰 접속 주소: 상단 [폰으로 공유] 버튼 클릭 후 표시되는 QR 코드 스캔 또는 IP 주소로 접속
